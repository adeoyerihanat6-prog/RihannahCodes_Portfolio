# RihannahCodes — Personal Portfolio

> A personal portfolio built to showcase my work, skills, and growth as a full-stack web developer.

**RihannahCodes** is my personal developer portfolio — a place where I showcase the applications I've built, the technologies I work with, and the way I approach creating for the web.

The website is intentionally minimal, dark, and editorial, with a focus on typography, spacing, motion, and thoughtful interactions rather than unnecessary visual clutter.

## Preview

**Live Website:** [rihannahcodesportfolio.vercel.app]

## About the Project

I wanted my portfolio to feel like an extension of how I like to build software: **intentional, clear, and functional.**

Instead of relying heavily on cards, gradients, or excessive effects, the design uses a warm dark palette, editorial typography, subtle borders, and restrained animations to create a calm browsing experience.

The portfolio includes:

* A personal introduction
* Selected projects
* A dedicated projects page
* About section
* Skills and technology stack
* Responsive navigation
* Smooth scroll-based animations
* Links to live projects and GitHub repositories

## Design Direction

The visual identity of the portfolio is built around a **late-night editorial** aesthetic.

### Principles

**Minimalism**
Every element has a purpose. The interface avoids unnecessary decoration and visual noise.

**Typography**
Large serif headings contrast with clean supporting text to create a strong editorial hierarchy.

**Motion**
Animations are subtle and intentional, helping guide attention without distracting from the content.

**Responsive Design**
The layout adapts across mobile, tablet, and desktop while maintaining the same visual identity.

**Dark Interface**
The portfolio uses a warm charcoal palette rather than pure black, creating a softer and more comfortable reading experience.

## Getting Started

Clone the repository:

```bash
git clone [YOUR_REPOSITORY_URL](https://github.com/adeoyerihanat6-prog/RihannahCodes_Portfolio)
```

Move into the project directory:

```bash
cd portfolio
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Deployment

The portfolio is deployed with **Vercel**.

Every production build is generated from the Vite application and served as a responsive frontend experience.
